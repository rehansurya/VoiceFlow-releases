# VoiceFlow for iPhone

Downloads for the VoiceFlow iPhone app (dictation app + keyboard). Source code lives in a private repository; this repo only hosts builds.

## Install with AltStore or SideStore (free Apple ID)

1. In AltStore (or SideStore): **Sources** tab → **+** → paste this URL:

   ```
   https://raw.githubusercontent.com/rehansurya/VoiceFlow-releases/main/source.json
   ```

2. Open the **VoiceFlow** source → **Install**. When asked, **Keep App Extensions** (the keyboard).
3. New builds show up as **Update** in the same place.

Direct IPA (latest): https://raw.githubusercontent.com/rehansurya/VoiceFlow-releases/main/VoiceFlow.ipa

## After installing

- Settings › General › Keyboard › Keyboards › Add New Keyboard › **VoiceFlow** → tap it → **Allow Full Access**.
- VoiceFlow app › Settings › paste your Groq API key › **Check key**.
- In any app: VoiceFlow keyboard → **Dictate** (first time the app opens for a second and returns) → talk → **Done**.

Free Apple ID limits still apply: AltStore/SideStore renews the 7-day signature automatically; 3 sideloaded app IDs at a time (AltStore + VoiceFlow + its keyboard).
